# 365 jours dans la House — Studio edition

Une édition plus éditoriale et premium du site souvenir de hol_rozuya pour le premier anniversaire de follow du 3 novembre 2026.

## Pages
- `index.html` — accueil et présentation
- `souvenirs.html` — chronologie symbolique
- `lettre.html` — enveloppe interactive et lettre
- `annee.html` — mise en avant des dates anniversaire
- `merci.html` — remerciements et accès discret à la surprise
- `surprise.html` — mini-page non présente dans la navigation, avec la proposition de giveaway
- `assets/style.css` — feuille de style séparée
- `assets/app.js` — interactions
- `assets/favicon.svg` — favicon

## Mise en ligne sur GitHub Pages
1. Décompresser le ZIP.
2. Envoyer l'ensemble du contenu à la racine du dépôt GitHub (les six pages HTML et le dossier `assets`).
3. Dans **Settings → Pages**, sélectionner la branche `main` et le dossier `/ (root)`.

Aucun framework, aucune installation, aucun serveur ou étape de compilation n'est nécessaire.

## Notes
- Le site n'utilise aucune photo réelle de Laura.
- Les souvenirs sont formulés de façon générale ; aucun événement privé ou détail précis n'est inventé.
- Le bouton discret en bas de `merci.html` mène à `surprise.html`.
- Le giveaway est formulé comme une idée personnelle, pas comme une annonce officielle de concours.
- Les polices web utilisent Google Fonts ; des polices de secours sont définies si le service est indisponible.
